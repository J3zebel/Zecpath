Microcontroller Programmer

Job Overview
Programs microcontrollers for controlling electronic devices and systems.
Responsibilities
• Write embedded code for microcontrollers
• Configure timers, interrupts, and peripherals
• Test and debug hardware behavior
• Develop small automation systems
• Interface sensors and actuators
Skills Required
• Embedded C programming
• Microcontroller architecture
• Basic electronics knowledge
• Programming tools (Keil, MPLAB)
